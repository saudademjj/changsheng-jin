# 长生烬

> 长明三千年，天门无归人。

完整六幕互动修仙文字志（React 19 + TypeScript + Vite），纯前端离线可玩，适配桌面端与移动端阅读排版。

## 在线试玩

- **在线地址**：https://saudade.me/changsheng-jin/

## 核心特性

- **六幕完整结构**：从十六岁踏入青岚界域，历经炼气、筑基、金丹、元婴直至化神叩天门，收束 12 种截然不同的终局。
- **四位宿命故人**：不限身世性别自由结缘，支持多伴侣同框交互、动态传记与跨卷因果回响。
- **世局坊市与奇物拼图**：随时代风声波动的坊市行市、18 件具名奇物与 12 块天机碎片，支持多周目「万象志」图鉴与随时回溯命盘。
- **古籍阅读排版**：宣纸 / 玄夜双主题、全站无横线无描边色块层次、逐段 / 瞬显切换、移动端安全区与手势触控优化。

## 本地运行

```bash
npm install
npm run dev
```
